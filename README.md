# ВебПрил — школа родов и материнства

Мобильный прототип приложения: «Сегодня», «Малыш», «Мама», «Мой путь», календарь беременности, курсы, клуб и AI-чат. Профиль пока представлен заглушкой. Данные демонстрационные.

Сайт: https://UncleMik.github.io/webappmappap/

## Публикация

Изменения в ветке `main` автоматически публикуются через GitHub Actions в GitHub Pages. В сайт включаются только HTML, CSS, JavaScript и ресурсы из `Фронт/`.

GitHub Pages публикует общедоступный статический прототип без авторизации. По текущему запросу пользователя обновления публикуются туда, без создания пароля и временного внешнего адреса.

## Структура

- `Фронт/` — страницы, стили, сценарии и ресурсы интерфейса; подробности в `Фронт/README.md`.
- `tools/` — локальные инструменты доступа и подготовки документов.
- Документы в корне — бриф и исследование приложения-референса.

Папка `данные/` с персональными данными исследования и локальные секреты `tools/preview-runtime/` исключены из Git. Для просмотра прототипа локально можно открыть `Фронт/index.html` в браузере. Работа сервера с паролем описана в `tools/ACCESS.md` и требует локальной конфигурации.
