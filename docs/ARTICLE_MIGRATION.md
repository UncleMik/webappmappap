# Перенос статей на wep_pril — 2026-10-06

Рабочий источник: SQLite на сервере `129.101.119.250`,
каталог `/opt/wep_pril/`. Структура и обслуживание описаны в
[`backend/README.md`](../backend/README.md).

Переносится фактический набор фронта: 126 статей, по три на недели 1–42,
без изменения текста, идентификаторов и отметок прочтения.
Иллюстрации взяты из предоставленной папки Google Drive «ФотоСтатьи».

## Иллюстрации

- В исходной папке 123 PNG. Все оригиналы сохранены отдельно на сервере.
- По названиям сопоставлено 122 статьи. Номер файла не использовался
  как единственное основание: в конце списка он расходится с номером статьи.
- 122 WebP занимают 155 686 308 байт вместо 222 957 590 байт соответствующих
  PNG: уменьшение на 30,2%. Сохраняются размеры и каждый пиксель исходника.
- Контроль идентичности пикселей выполнен для всех WebP; отчёт с SHA-256
  хранится на сервере в `deploy/import/migration-report.json`.
- Исходник `115 Как облегчать схватки ... .png` дублирует тему файла 116.
  Для статьи о схватках выбран файл 116; оба оригинала сохранены.

## Границы этапа

Рабочий фронт остаётся на GitHub Pages, статьи и картинки загружает с сервера.
Архив документа в `docs/content/pregnancy-articles/` сохраняется как исходный
материал и в сайт не публикуется. Иконки и постоянные ресурсы интерфейса
остаются во фронте. Админ-панель, вход, платные права, клуб и AI не входят
в этот перенос.
