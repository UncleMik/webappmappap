# Меню дыхательной практики

2026-10-27: по прямой просьбе пользователя при переходе «Сегодня → Дыхание»
показывается общее нижнее меню из пяти разделов без активного пункта.
Это действует при проверке доступа, отказе, ошибке и после открытия урока.
Маркер from=index-breathing передаётся только при этом переходе;
обычные уроки курсов сохраняют выделение «Мой путь».

Проверено в Chromium: 390×844 и 1280×900, закрытый доступ, переход
к доступному уроку на тестовых ответах API, обновление страницы и обычное
открытие урока курса. Меню остаётся у нижней границы. Шесть проверок
маршрутов школьных видео прошли. Реальное платное видео этой правкой
не проверялось; проверка прав остаётся в существующем серверном API.

Публикация: deploy/publish-breathing-navigation.py, семь файлов интерфейса,
проверка исходных хешей, резервная копия и откат при ошибке, без перезапуска служб.
