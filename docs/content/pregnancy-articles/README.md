# Статьи о беременности по неделям

Материалы предоставлены пользователем 5 октября 2026 года в документе
«Статьи_о_беременности_1–42_недели.docx» для добавления в бэкенд.

## Сохранённые материалы

- `articles.json`: 126 статей, по три на каждую неделю с 1-й по 42-ю.
  Каждая статья содержит номер из документа, неделю, заголовок и текстовые
  блоки в исходном порядке. Подзаголовки и пункты списков выделены по стилям
  Word. Нумерованные пункты, записанные обычным текстом, сохранены целиком.
- `editorial-sources.json`: отдельный редакционный раздел с 20 ссылками.
  Он не включён в тексты статей.

Формулировки сохранены без редакторских изменений. Оглавление, номера
страниц и служебные обозначения недель и статей не включены в основной текст.
Поле `image` пока равно `null`: фотографий в исходном документе нет.
Идентификаторы `pregnancy-001`–`pregnancy-126` позволяют позднее связать
фотографии с нужными статьями.

В `articles.json` записаны имя и SHA-256 исходного документа. Проверены
количество статей, непрерывная нумерация 1–126, наличие трёх статей на
каждую неделю, сохранность всех 2363 блоков текста и чтение сохранённого JSON.

## Подключение

5 октября 2026 года по прямому поручению пользователя материалы подключены
к статическому прототипу: по три статьи на каждую неделю в «Моём пути» и
в общей библиотеке. `Фронт/pregnancy-articles-data.js` содержит тот же набор
статей для браузера. Читатель сохраняет подзаголовки, абзацы и списки.
До получения фотографий используются нейтральные обложки.

Редакционные источники не включены в пользовательские статьи и публикацию.
Настоящий бэкенд, база данных и правила доступа GetCourse остаются частью
отдельного архитектурного обсуждения.
