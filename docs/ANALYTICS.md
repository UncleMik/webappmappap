# Аналитика использования приложения

Согласовано 2026-11-14: выбрать основные события самостоятельно и реализовать
общую статистику в отдельной вкладке «Аналитика» существующей админки.
Сбор — на существующих Node.js, PostgreSQL и Timeweb. Доступ к отчётам —
только владельцу. Срок хранения событий — 90 дней.

## Что измеряем

| Показатель | Определение |
| --- | --- |
| Пользователи | Разные авторизованные аккаунты с событиями за выбранный период; служебные и отмеченные тестовые аккаунты исключены. |
| Открытия экранов | Реальный показ экрана после входа, включая возврат в сохранённую вкладку приложения. Предзагрузка и скрытая вкладка не считаются просмотром. |
| Активное время | Время видимого экрана при недавнем взаимодействии либо воспроизведении видимого видео. После 60 секунд без действий время приостанавливается. Это приблизительная оценка внимания. |
| Материалы | Открытия статей, видео, уроков и курсов после успешной загрузки их данных. |
| Чтение статей | Достижение 25/50/75/90% прокрутки; конец страницы вместе с активным временем — признак дочитывания, а не доказательство понимания текста. |
| Видео | Подтверждённый запуск и достигнутые участки воспроизведения. Открытие внешнего плеера отдельно; без данных плеера оно не считается просмотром. |
| Нажатия | Переходы навигации, открытие материалов, избранное, баллы, календарь и основные действия AI. Произвольные координаты и текст элементов не собираются. |
| Переходы | Явный переход между известными экранами; не восстановленный по порядку получения сетевых запросов. |
| AI | Формат обращения, начало/результат обработки, ошибки и достижение лимита; содержание вопроса и ответа не передаётся. |

Открытие экрана, открытие материала, прогресс просмотра и завершение действия
считаются разными событиями. Число пользователей вычисляется по уникальным
аккаунтам, а не суммированием строк отчёта. Данные клиента описывают
поведение в интерфейсе и не заменяют серверный учёт покупок и выдачи доступа.

## Данные и доступ

- Событие содержит случайный идентификатор, известный экран, тип действия,
  идентификатор материала и ограниченные числовые показатели.
- Аккаунт определяется сервером по текущей сессии, не принимается из тела
  события. Повторная отправка того же события не увеличивает показатели.
- Не собираются имя, email, содержимое полей и переписки, фотографии,
  документы, показатели здоровья, полные URL с параметрами, IP и User-Agent.
- Владелец, сотрудники и явно отмеченные сервером тестовые аккаунты
  исключаются из показателей учениц. В отчётах нет списка отдельных учениц.
- События старше 90 дней не включаются в отчёты и удаляются регулярной
  очисткой. Сроки хранения остальных данных продукта этим не меняются.
- Недоступность аналитики не блокирует обучение, чат и другие действия.

## Отчёт

Период — последние 7, 30 или 90 календарных дней по Москве, включая сегодня.
Показываются начало сбора и время формирования отчёта, общие показатели,
популярные экраны и материалы, просмотр видео, нажатия, переходы и AI.
До первых посещений выводится честное пустое состояние.

Аналитика начинается с внедрения: прошлые действия не восстанавливаются
из наград и отметок завершения. Существующие показатели возвратов пилота
геймификации остаются отдельными и не смешиваются с новой историей.

Перед добавлением таблиц выполняются резервное копирование и проверка
восстановления в отдельную временную базу. При откате кода новые таблицы
сохраняются, чтобы не потерять уже принятые события.
