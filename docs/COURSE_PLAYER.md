# Плеер уроков курса

Согласован 26 октября 2026: образец — бесплатный урок «Витамины и дефициты
во время беременности». Существующие курс, раздел, урок и вкладки сохраняются.

## Отображение и управление

`course-video-player.js` монтирует GetCourse-видео с обложкой, фиолетовой
кнопкой запуска, полосой перемотки, оставшимся временем и кнопками
«Предыдущий урок / Воспроизведение или пауза / Следующий урок» под видео.
Общие стили бесплатного урока берутся из `video.css`, адаптация курса —
из `course-player.css`. Размер видео после загрузки учитывает пропорции файла.
Полноэкранный режим содержит видео и управление; при недоступности Fullscreen
API используется нативный полноэкранный режим Safari, если он доступен.

Стрелки используют разрешённую сервером программу и переходят между уроками,
включая соседние разделы. На первом/последнем уроке стрелка отключается.
Окончание видео само по себе не открывает другой урок и не отмечает прохождение.
Запуск другого ролика останавливает предыдущий. YouTube/Rutube сохраняют
встроенное управление провайдера и получают обложку и стрелки уроков;
управление временем/паузой этих сервисов через их API не реализовано.

`course-video-chapters.js` извлекает время и подписи из исходных двухколоночных
таблиц урока. Связь — с ближайшим предыдущим видеоблоком с одним GetCourse-видео;
новый видеоблок или сообщение об удалённом видео сбрасывают привязку.
Несколько источников, неверные времена и неоднозначные таблицы не превращаются
в кнопки. Поддержаны MM:SS и H:MM:SS. Для перенесённых таблиц сохраняется
источник на сервере, а вместо повторной таблицы в интерфейсе показан список
при видео. Первый плеер и его тайм-коды находятся над вкладками; дополнительные
видео и их тайм-коды остаются на исходных местах во вкладке «Об уроке».

## Доступ

Управление использует текущую проверку `createCourseView`. При скрытии страницы,
ошибке, истечении или отзыве сессии источники удаляются и плеер закрывается,
в том числе в полном экране. Успешная периодическая проверка сохраняет позицию
и состояние воспроизведения только в памяти страницы. Покупки, БД, видеореестр
и схема выдачи постоянных URL не изменены. Стандартной панели скачивания нет;
скачивание файла по полученному прямому URL по-прежнему возможно.

## Проверки

- Девять Node-проверок: жизненный цикл доступа и привязка исходных тайм-кодов,
  включая удалённые видео, несколько источников и неверное время.
- Изолированный Chromium, реальные тексты/таблицы Экспресса из приватного
  снимка, синтетические права и локальные тестовые MP4, без локального сервера.
- 15 проверок трёх уровней курса на ширинах 320/390/430/500/1280: без
  горизонтального переполнения; просмотрены снимки интерфейса.
- Проверены точные подписи/время из таблиц, запуск с тайм-кода до метаданных,
  пауза, перемотка клавиатурой, полный экран, успешное восстановление позиции,
  503 при повторной проверке и выход из полного экрана, ошибка видео и повтор,
  стрелки уроков и граница курса, несколько видео, очистка при скрытии страницы,
  сохранение iframe внешнего провайдера и его стрелок.
- Артефакты: `output/playwright/course-player/`, в Git не включаются.

Реальная платная сессия ученицы, физические iPhone/Android и полное
воспроизведение внешних видео не проверены. Нагрузка этим выпуском не проверяется.

## Выпуск

`deploy/publish-course-player.py` обновляет шесть файлов интерфейса с проверкой
старых/новых SHA-256, резервной копией и откатом при ошибке. Службы не
перезапускает. Версии импортов и подключения страницы обновлены для сброса кэша.
