# Краткие описания над видео

## Бесплатные видео по неделям: редактура 11 ноября 2026

По просьбе пользователя у всех 125 доступных недельных видео описание
составлено по расшифровке соответствующего фрагмента, а не из заголовка.
Источник — `АнализКонтентаСущ/course-batch-03/document-plan.json`, поля
`number`, `title`, `transcript`; данные сверены с планами первых двух партий.
Позиция 75 отсутствует в опубликованном каталоге и не добавляется.

Вводная «В этом видео мы рассмотрим:» и короткие пункты над плеером
сохранены. Пункты называют конкретные вопросы, приёмы или действия из
записи. Дозировки, медицинские назначения и обещания лечебного эффекта
в описания не переносятся. Полные расшифровки остаются в исходном проекте.
Названия, распределение по неделям, таймкоды и правила просмотра сохранены.

Проверка 11 ноября: все 125 описаний в Chromium на ширине 390 px;
видео №122 дополнительно на 320 и 1440 px. Проверены точный текст,
переносы, расположение перед плеером и отсутствие горизонтальной прокрутки;
мобильный снимок просмотрен визуально. Сравнение каталога до и после
подтвердило сохранность всех полей, кроме тезисов. Браузер использовал
подставленные ответы API; реальный вход ученицы в эту проверку не входит.

Ниже — прежняя реализация описаний платных уроков и проверка от 28 октября.

Согласовано 28 октября 2026: над каждым видео, включая платные курсы,
показывать краткое описание в нескольких предложениях. Основа — материалы
соответствующего урока GetCourse.

Курсы используют `course-video-description.js`: краткий текст из таймкодов
конкретной записи или вводного описания рядом с ней. Описания меняются вместе
с выбранным видео. Исходные объяснения, инструкции, ограничения и материалы
остаются полностью доступны в тексте урока. Новые медицинские утверждения
не добавляются. Когда вводного текста нет, показываются только подтверждённые
название записи и её принадлежность уроку; содержание видео не выдумывается.

Текст формируется после успешной серверной проверки урока. Отдельного публичного
реестра описаний платных видео нет; отказ доступа удаляет описание вместе с
материалами. Источники и права на просмотр не изменены.

У трёх бесплатных недельных видео краткое описание перенесено над плеером;
повтор под плеером убран. Их тексты сокращены до двух предложений по источнику.

Проверки 28 октября:

- Свежая копия исходных текстов из SQLite, без изменения базы: 657 уроков,
  1147 видеовставок, пустых описаний нет, максимальная длина 402 символа.
  У 856 вставок доступно только описание по названию/принадлежности уроку.
- 17 тестов: выбор источника, отсутствие заимствования текста соседнего видео,
  исключение служебных ссылок и обрезанных инструкций, сохранение закрытого
  доступа при 401/403/503, подзаголовки и жизненный цикл материалов.
- Chromium с локальной подстановкой файлов и ответов API без запуска сервера:
  320/390/1440 px, описание выше видео без горизонтального переполнения,
  изменение текста при выборе подтемы, удаление текста при отказе 403.
  Отдельно проверены бесплатные видео на тех же ширинах.
- Полное прослушивание всех записей, вход реальной платной ученицы и физические
  телефоны в эту проверку не входят.

Публикация меняет только перечисленные статические файлы, с проверкой исходных
хешей, резервной копией и откатом; службы и базы не перезапускаются.
