# Документы приложения

Источник — Google Docs «Приложение ЛР», редакция от 9 ноября 2026 года.
«О приложении», условия и политика открываются из «Профиль → Другое».
Условия и политика доступны также со страницы входа, без авторизации.
Сценарий входа и обработку данных эта публикация не меняет.

Общие стили и «О приложении» находятся в `Фронт/`. Два документа с
реквизитами собираются из шаблонов `deploy/legal/`. Для обновления:

```powershell
python tools/render-legal-pages.py <private-operator-details.json> <output-directory>
```

В приватном JSON задаются строки `operator_name`, `operator_inn`,
`operator_ogrnip`, `operator_address_terms` и `operator_address_policy`
с написанием из исходного документа. Не добавлять JSON или собранные
страницы в Git. На Timeweb собранные `terms.html` и `privacy.html` лежат
в `/opt/wep_pril/legal/`, отдельно от заменяемого каталога фронтенда.
Nginx отдаёт только эти два файла по точным публичным адресам. При
публикации обновлять точечные маршруты в действующей конфигурации,
сохраняя остальные настройки. «О приложении» остаётся за входом.
