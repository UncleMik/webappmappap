# Переход в обсуждение опроса — исправление 2026-11-11

Пользователь сообщил, что вместо обсуждения отображается экран входа
с логотипом и иллюстрацией. По журналу Timeweb переход к отдельной комнате
`weekly-poll:<pollId>` сопровождался перенаправлениями на вход.

В проверке сессии воспроизведена гонка: после ухода со страницы отменённый
запрос вызывал переход на вход. Теперь скрытие/уход со страницы отменяет
актуальность результата проверки. После возвращения запускается новая
проверка; поздний ответ старой не закрывает новую страницу.

Текущая ошибка проверки, отзыв сессии и смена аккаунта по-прежнему
закрывают доступ. Серверная авторизация не изменена. Чаты остаются
отдельными для каждого опроса, с проверкой голоса и срока опроса на сервере.

Проверка: `node --test tools/test-auth-gate.mjs tools/test-auth-return.mjs`.
До исправления два сценария воспроизводили ошибку; после проходят все шесть.
Публикация заменяет только `auth-gate.js`, с проверкой исходного SHA-256,
резервной копией и атомарной записью; перезапуск служб не требуется.
