## 2026-10-26 — Плеер курсов по образцу бесплатного урока

Основание: пользователь попросил повторить вид бесплатного урока и ответил
«да» на три уточнения: образец — «Витамины и дефициты во время беременности»;
стрелки переключают уроки курса; вкладки «Об уроке / Материалы» сохраняются,
тайм-коды берутся только из исходного урока GetCourse.

- Для прямых GetCourse-видео — оформление и собственные элементы управления
  бесплатного урока: просмотр по нажатию, пауза, полоса перемотки, оставшееся
  время, полный экран. Кнопки скачивания нет; защита самого файла не меняется.
- Стрелки идут к предыдущему/следующему доступному уроку по серверной программе,
  включая границы разделов; на границах курса соответствующая стрелка отключена.
- Исходные тайм-коды показываются кликабельным списком под управлением нужного
  видео. У первого видеоблока — над вкладками; остальные видео остаются на своих
  местах в тексте. Перенесённая таблица заменяется списком без дублирования.
  Если времени в источнике нет либо привязка неоднозначна, его не придумывают.
- YouTube/Rutube сохраняют управление собственного встроенного плеера и получают
  такое же оформление обложки и стрелки уроков. Их управление через API сервисов
  этим изменением не добавляется.
- Существующие покупки, сроки проверки и закрытие при потере доступа сохраняются.
  Проверки и выпуск: [плеер курсов](COURSE_PLAYER.md).

## 2026-10-26 — Реальные права на карточках курсов в «Моём пути»

Основание: после проверки замков на купленных курсах пользователь подтвердил
предложение «купленный курс открывает уроки, недоступный — тарифы; дизайн сохраняем»
словом «Делай».

- Карточки строятся по настоящим учебным продуктам текущих тарифов GetCourse,
  без шаблонного соответствия «Здоровая спина» или «Эмоциональная уверенность».
  Повторяющиеся продукты объединяются; доступные текущему аккаунту идут первыми.
- Доступ определяется только существующим защищённым `/api/auth/courses`.
  Купленная карточка без замка ведёт к её разделам в «Моих курсах»;
  остальные с замком — к существующей витрине тарифов.
- «Все курсы» ведёт в «Мои курсы». При отсутствии доступных продуктов там есть
  переход к тарифам. Сохраняются прежние оформление карточек и карусель.
- Загрузка и ошибки проверки отображаются явно. Статус не хранится в localStorage;
  истечение, возврат и ошибка используют общий жизненный цикл платных материалов.
  Покупки, сроки, условия уроков и выдача видео на сервере не меняются.
- Реализация и проверка: [карточки курсов](JOURNEY_COURSE_ACCESS.md).

## 2026-10-24 — Одна активная сессия на аккаунт

Основание: пользователь поручил сначала составить и согласовать план,
затем подтвердил его: «Да, согласовал план делаем».

- Последний успешный вход в аккаунт отзывает все предыдущие сессии.
  Несколько вкладок одного профиля браузера разделяют одну сессию.
  Запрос письма, неверный код и неуспешное завершение старый вход не прерывают.
- Ограничение действует на сервере и в PostgreSQL, включая одновременные
  входы. Срок сохранения входа остаётся до 30 дней.
- Открытый интерфейс проверяет сессию каждые 30 секунд в видимой вкладке,
  при возврате и восстановлении. При отзыве закрываются сохранённые панели,
  останавливается видео и выводится сообщение о входе в другом браузере
  или на другом устройстве. Ошибка проверки не открывает доступ.
- При обновлении сохраняется только последняя созданная действующая сессия
  каждого аккаунта; прежние отзываются после резервной копии.
- Уже загруженные материалы и выданные прямые ссылки GetCourse отозвать
  этим механизмом нельзя; защита доставки видео остаётся отдельным вопросом.
- После проверок исходники обновляются в GitHub, приложение — только Timeweb.
  Реализация, выпуск и проверки: [одна сессия](SINGLE_SESSION.md).

## 2026-10-24 — Временный просмотр платных видео по постоянным ссылкам

Основание: пользователь разрешил временно подключить платные видео по прямым
постоянным ссылкам GetCourse, по аналогии с тремя бесплатными, с проверкой
фактических покупок и пятиминутным сроком результата.

- Ссылка выдаётся только из защищённого урока после действующей сессии,
  заполненного профиля, покупки конкретного продукта, периода доступа,
  условий всех дочерних разделов, расписания и стоп-уроков. При сбое или
  истечении проверки приложение убирает видео и повторно проверяет право.
- Файлы остаются на GetCourse; на Timeweb их не копируют. Исходные видео
  YouTube/Rutube в уроках сохраняются без расширения покупных прав или
  добавления произвольных видеохостингов.
- Постоянные URL хранятся в отдельном приватном реестре SQLite, вне Git и
  webroot. Отсутствующая или повреждённая запись не открывает ролик.
- Полученный браузером прямой URL можно скопировать: пятиминутная проверка
  ограничивает выдачу ссылки приложением, но не отзывает саму ссылку и не
  защищает прямой запрос к видеохостингу. Поддерживаемое защищённое
  встраивание GetCourse и DRM остаются открытыми вопросами.

Решение 23 октября «держать все платные видео закрытыми до ответа GetCourse»
заменено этим временным вариантом. Реализация, полнота сопоставления ссылок,
публикация и живой просмотр всех роликов проверяются отдельно. Выпуск 24 октября
подключил 1147 видеовставок в 657 уроках; покупки и прежние условия доступа
сохранены. Проверки и ограничения описаны в [источниках видео](VIDEO_INTEGRATION.md).

## 2026-10-23 — Пятиминутная проверка платного доступа

Основание: пользователь подтвердил предложенный вариант — проверять права
каждые пять минут и при устаревшей проверке закрывать платный материал.

- При открытии курса или урока сервер использует результат GetCourse не
  дольше пяти минут. После истечения срока требуется новое успешное чтение.
- Если обновление не удалось, устаревший результат не разрешает выдачу
  платного материала. Ещё действующий результат сохраняет первоначальный
  срок; вход, обновление страницы и ошибка его не продлевают.
- Результат связан с внутренней карточкой и ID GetCourse и сохраняется в
  ранее согласованной PostgreSQL. Создание покупок и прав в GetCourse не
  выполняется. Это решение не определяет семантику флагов покупки,
  условия дочерних уроков или способ защищённой доставки видео.

Серверная проверка свежести и её ограничения:
[COURSE_ACCESS_CHECKS.md](COURSE_ACCESS_CHECKS.md).

## 2026-10-23 — Проверка чтения Tech API с ключами школы

Основание: пользователь передал ключ разработчика и отдельный API-ключ
школы для продолжения ранее согласованной интеграции с «Лёгкими родами».
Оба секрета сохранены вне проекта в закрытом серверном файле root 0600;
ключ регистрации и действующая конфигурация входа не менялись.

На `legkierody.ru` успешно проверены четыре GET-метода Tech API:
каталог тренингов, карточка пользователя, покупки и доступные тренинги.
Добавлен отдельный серверный клиент без HTTP-маршрутов выдачи материалов,
изменения покупок или автоматической синхронизации. Реальная старая покупка
продукта из Экспресс совпала с интерфейсом школы по ID и срокам доступа.
При этом у оплаченного заказа `is_actual=1`, `is_payed=0`, `state=null`:
флаг оплаты не определяет права сам по себе. Бесплатная контрольная
карточка имеет 80 доступных тренингов при отсутствии покупок.

Получение ключей больше не блокирует чтение API. Эти проверки не означают,
что платные права или видео уже выдаются приложением. Срок актуальности
результатов, поведение при сбое, условия дочерних тренингов и защищённая
доставка видео остаются открытыми. Подробности — в
[описании проверки](GETCOURSE_TECH_API_SETUP.md).
