# Согласованные решения — ВебПрил

Здесь хранятся согласованные решения проекта. Общие правила работы
находятся в [AGENTS.md](../AGENTS.md), правила интерфейса —
в [Фронт/AGENTS.md](../Фронт/AGENTS.md).

## Порядок ведения

- Перед работой читать решения, относящиеся к задаче.
- Записывать только согласованные с пользователем решения.
  Предложения агента и предположения не считать согласованием.
- Для каждого решения указывать дату, содержание и основание согласования.
- После фиксации решения убирать соответствующий закрытый вопрос
  из раздела 12 корневого `AGENTS.md`.
