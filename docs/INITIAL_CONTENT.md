# Первый показ страниц

Обновлено 20 октября 2026 по просьбе убрать краткий показ старых шаблонов.

## Как устроено

video.html содержит нейтральные подписи и data-video-pending. Пока video.js
или weekly-video-player.js не подготовили нужный плеер, его блок невидим.
Успех и ошибка снимают ожидание; ошибка не запускает демо как запасной вариант.
Все три известные записи выбираются по ID независимо от места перехода.

account-profile.js публикует webprilProfileReady. mom-week.js, baby-week.js
и journey-week.js ждут его до первого построения данных. Все подключения
используют одинаковую версию модуля, включая mom/baby/personal-data HTML
и app-navigation.js. При ошибке профиля показывается ошибка с предложением
обновить страницу; временная неделя 27 не подставляется.

Исходный HTML mom/baby нейтрален. Ссылка baby на материалы не имеет href,
пока выбранная неделя не получена. Статья изначально имеет aria-busy=true;
панель завершения скрыта существующим CSS. Прогресс скрыт до updateProgress.
Серверные проверки входа и auth-gate.js не менялись.

## Проверка

В Playwright на изолированной странице с моделируемой сессией и реальными
материалами сервера прошли 20 сценариев задержек, ошибок, прямых переходов,
обновления, личной/явной недели и ветки «Я уже мама», включая возврат фокуса во время первоначальной
проверки профиля. На видео проверены
ширины 320, 390, 500, 1440 и запуск настоящего MP4. Локальные сценарии и
результаты: output/playwright/initial-content/ (в Git не входят).

Существующие проверки account UI и auth return прошли. Полный запуск трёх
старых файлов тестов дал 12/13: tools/test-profile-dates.mjs всё ещё ожидает
запрета возврата к другим внутренним страницам, хотя текущий auth-return.js
уже разрешает безопасные адреса разделов. Тест, auth-return.js, profile-dates.js
и серверный profile.mjs побайтно соответствуют исходному HEAD до этой задачи;
этот отдельный устаревший тест в рамках исправления вспышек не менялся.

## Публикация

Точечный выпуск изменённых файлов интерфейса выполняется через согласованный
SSH. До записи проверяются SHA-256 исходного HEAD; предыдущие версии
сохраняются в закрытый каталог root. Общая транзакция откатывает файлы
при ошибке. Базы, nginx и службы не меняются. GitHub Pages сохраняет
перенаправление на основной домен с обязательным входом.

19 файлов опубликованы на Timeweb с итоговой сверкой хешей. Отдельное
уточнение готовности профиля проверено и доставлено в том же выпуске.
