# Проверка тематического каталога — 2026-11-13

## Реализация

«Все программы» открывает существующий тематический каталог независимо
от покупки. Маршрут `my-courses.html?programs=1` больше не подменяет его
тремя тарифами; старые тематические адреса поддерживаются.
В закрытой теме, подразделе и программе перед материалами находится
«Посмотреть тарифы» со ссылкой на `https://legkie-rody.ru/tarif`.
Правила покупки и серверной выдачи уроков не менялись.

## Проверки

- Локальный набор: `node --test tools/test-journey-courses.mjs tools/test-course-layout-view.mjs tools/test-course-program-locks.mjs tools/test-course-video-topics.mjs` — 24/24.
- Браузер с опубликованным каталогом и синтетическими учебными правами:
  без покупки, частичный доступ и доступ к продуктам с уроком, закрытым
  по условию. Темы остаются видны; разрешённый урок сохраняет переход,
  закрытый не получает ссылки на содержимое. При доступном продукте одно
  ограничение урока по условию не вызывает предложение выбрать тариф.
- Проверены возврат, reload, старые express/full URL, состав отдельного
  тарифа, одна кнопка в пустой теме и отсутствие каталога/покупки при 503.
  Переполнения по ширине нет на 320/390/500 px.
- На опубликованном HTTPS с отдельным временным аккаунтом без покупок:
  настоящий переход «Мой путь → Все программы» открыл 12 тем, далее тему
  и подраздел с 78 закрытыми уроками. Кнопка тарифов находится под заголовком
  и полностью видна в viewport 390×844; возврат и reload работают.
- Настоящий API вернул пустые покупки, программу с метаданными и 403 на
  содержимое закрытого урока. Для тестового аккаунта использовался только
  пустой снимок прав, без выдачи платного доступа и внешних GetCourse-действий.
- Временные аккаунты, сессии, пустые снимки прав и файлы полномочий удалены;
  прежние тестовые cookie больше не подтверждают вход.

## Публикация и границы

Код опубликован в `origin/main` и на Timeweb: `267e07b`, затем `2eee889`
с расположением кнопки перед списком. Опубликованы только три файла
интерфейса с проверкой исходных и итоговых SHA-256, резервными копиями
и проверкой здоровья. Сервисы не перезапускались, схема не менялась.

Реальный платный аккаунт и оформление платежа не использовались.
Частичный доступ проверен с фикстурами; нагрузочное испытание не проводилось.
