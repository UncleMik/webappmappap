визуальный пример: «Все корректно. Делай такое письмо».

- Голубой баннер школы, приветствие, крупный код в светлой плашке,
  срок действия 5 минут, красная кнопка «Открыть приложение», предупреждение
  о безопасности и подпись школы — как в согласованном примере.
- HTML использует таблицы, основные стили заданы непосредственно на элементах;
  для узких экранов предусмотрены меньшие отступы. Есть текстовая версия.
- Код остаётся переменной `{{code}}`, подставляемой действующим адаптером.
- Баннер получен браузерным рендером соответствующего фрагмента присланного
  пользователем образца, размер 600 × 186. Фотографии и логотип не генерировались.

Исходники: `backend/auth/email/login-code.html`, `login-code.txt`, `school-banner.png`.
Обновлён существующий шаблон, выбранный `UNISENDER_TEMPLATE_ID` на Timeweb.
Тема, отправитель, ID шаблона, настройки приложения, правила отписки,
лимиты и правила входа сохранены. Перезапуск служб не требовался.

## Публикация и повторная проверка

Скрипт `deploy/publish-auth-email.mjs` запускается на Timeweb от root:

```sh
node --env-file=/etc/wep-pril/auth.env /opt/wep_pril/deploy/publish-auth-email.mjs --verify
```

Режим `--apply` обновляет известный текстовый шаблон, сначала сохраняет его
закрытую копию в `/root/wep-pril-auth-email-backup-<timestamp>/template.json`
с правами 0600, затем проверяет результат через `template/get`. При уже
совпадающем шаблоне запись не повторяется. Другой существующий дизайн требует
отдельного просмотра; скрипт не заменяет его вслепую. Писем скрипт не отправляет.

При публикации 10 ноября создана копия:
`/root/wep-pril-auth-email-backup-1794310551571/template.json`.
При необходимости её объект `template` можно вернуть через `template/set`
с серверным API-ключом; после восстановления проверить `template/get`.
Секреты и резервная копия в Git не сохраняются.

Unisender принимает баннер как `inline_attachments`, но при чтении шаблона
возвращает `filePath` в своём HTTPS-хранилище и заменяет `cid:` в HTML этой
ссылкой. Проверка учитывает именно это преобразование: загружает изображение
с разрешённого домена и сравнивает его байты с исходником. Также учитываются
удаление крайних пробелов и пустые служебные поля редактора. Обычный текст,
разметка и остальные настройки должны совпадать.

Описание API: https://godocs.unisender.ru/web-api-ref (методы template/set и template/get).

## Результат проверки

- Провайдер подтвердил сохранение; повторное чтение подтвердило HTML,
  текстовую версию, переменную кода и точные байты баннера.
- Остальные поля сверены с исходной резервной копией; они сохранены.
- Локальный макет проверен в Chrome при ширине 760 и 390 пикселей:
  баннер загружен, горизонтального переполнения нет.
- После публикации отдельно скачан HTML из Unisender и проверен в Chrome
  при тех же ширинах. Баннер загружается из хранилища провайдера,
  переполнения нет; снимки — `output/playwright/email-code-live/`.
- Исходники установлены на Timeweb; `--verify` прошёл из `/opt/wep_pril`.
  Служба входа после обновления активна.
- Проверка получения реального письма и отображения в Gmail, Яндекс,
  Mail.ru или Outlook этим обновлением не выполнялась; контрольное письмо
  не отправлялось. Браузерная проверка не заменяет проверку почтового клиента.
