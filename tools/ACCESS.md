# Доступ к ВебПрил

Основной сайт: https://unclemik.github.io/webappmappap/.

Локальный сервер, Cloudflare Tunnel и автозапуск `WebPril-Access` отключены
по просьбе пользователя 19 сентября 2026 года. Уведомления с адресом туннеля
и данными для входа больше не отправляются. Не восстанавливать локальный
запуск без новой прямой просьбы пользователя.

Ниже сохранена справка о прежней схеме доступа; это не инструкция запускать её.

## Прежняя схема локального доступа (отключена)

Сайт работает в фоне через задачу Windows `WebPril-Access`. Закрытие Codex или
браузера не останавливает его. Локальный адрес — http://127.0.0.1:5173.

Публичный HTTPS-адрес создаёт Cloudflare Tunnel. После запуска туннеля и при
смене адреса контроллер сначала проверяет ответ сайта с авторизацией, затем
отправляет ссылку, логин и пароль в существующий разрешённый Telegram-чат.
Используется `send-media.mjs` из проекта HotVPN/Hot_TG — тот же отправитель,
на который ссылается проект «Заводик». Подтверждение доставки хранится без
секретов в `preview-runtime/status.json`.

## Запуск и восстановление

- `install-access.ps1` устанавливает и запускает задачу Windows. С правами
  администратора используется запуск при загрузке ОС под SYSTEM. При отсутствии
  таких прав используется запуск после входа текущего пользователя в Windows.
- `start-access.ps1` запускает контроллер скрыто и восстанавливает его через
  10 секунд после завершения процесса. Задача Windows также имеет повторный запуск.
- Пока задача работает, она запрашивает запрет автоматического сна. Ручной сон,
  выход из учётной записи, выключение ПК и отсутствие интернета прерывают доступ.
- Контроллер проверяет публичный адрес каждые 30 секунд. После шести неудач при
  работающем локальном сервере пересоздаёт туннель. Завершившийся туннель
  запускается снова через 15 секунд. Новый адрес отправляется в Telegram.
- Логин и пароль сохраняются при перезапусках. Их локальная копия находится в
  `preview-runtime/access.json`, вне папки сайта; доступ ограничен ACL Windows.
  Токен Telegram в этот проект не копируется.

Установка или повторная настройка из корня проекта:

```powershell
& ./tools/install-access.ps1
```

Для запуска до входа в Windows эту же команду нужно выполнить в PowerShell
с правами администратора. После смены режима остановить старую задачу и
запустить её снова; проверять результат через `Get-ScheduledTaskInfo` и status.json.

## Проверка и остановка

```powershell
Get-ScheduledTask -TaskName WebPril-Access
Get-Content ./tools/preview-runtime/status.json
node ./tools/verify-access.cjs
```

По прямой просьбе пользователя повторно отправить проверенную актуальную ссылку,
логин и пароль:

```powershell
node ./tools/send-current-access.cjs
```

Подтверждение этой ручной отправки — `preview-runtime/manual-delivery.json`.

Остановить и отключить автозапуск:

```powershell
Disable-ScheduledTask -TaskName WebPril-Access
Stop-ScheduledTask -TaskName WebPril-Access
```

Если Telegram вернул неоднозначный ответ, `telegram.status` будет `uncertain`
или `sending`. Такой же адрес не отправляется повторно вслепую. Сначала проверить
чат. `delivered` и `messageId` означают подтверждение отправителя и allowlist.

Cloudflare Quick Tunnel даёт меняющийся адрес и не гарантирует непрерывную
доступность: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/
